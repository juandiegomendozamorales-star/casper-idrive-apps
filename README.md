# Apps de Jorge para iDrive 8

Apps propias para el iDrive 8 (MGU), instaladas desde la [MGU Store](https://github.com/robertnisipeanu/mgu-store).

## Apps

- **PEREA PERFORMANCE** (`jorge_suite`): ESSENTIALS configurable (1 a 8 recuadros con los datos de MHD), etanol, calculadora, density altitud y tiempos en una sola app. Para iDrive 8 y iDrive 7 (en iDrive 7 las letras salen más grandes; los botones táctiles necesitan "Pantalla completa con GPU").

- **FLEX FUEL** (`jorge_flexfuel`, Perea Performance): etanol del sensor flex fuel, gasolina en galones y calculadora de cuánto etanol agregar.

- **DENSITY ALTITUD** (`jorge_density`): density altitude en metros, presión, temperatura afuera e IAT, y el tiempo de 1/4 de milla corregido al nivel del mar. También para iDrive 7, con su propia vista para esa pantalla (1920 × 720).

- **ESSENTIALS** (`jorge_essentials`): IAT, aceite de motor, aceite de caja y refrigerante en grande, rangos propios en °F y minutos para estar listo.

- **CASPER DRAGY'S** (`jorge_dragtimer`): 0-100, 100-200, 1/8 y 1/4 de milla con récords, usando los sensores del carro.

## Instalar

En el carro: Store → Ajustes → Agregar fuente → este repositorio, rama `main`. Instala la app y reinicia la unidad.
