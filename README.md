# Apps de Jorge para iDrive 8

Apps propias para el iDrive 8 (MGU), instaladas desde la [MGU Store](https://github.com/robertnisipeanu/mgu-store).

## Apps

- **DENSITY ALTITUD** (`jorge_density`): density altitude en metros, presión, temperatura afuera e IAT, y el tiempo de 1/4 de milla corregido al nivel del mar.

- **ESSENTIALS** (`jorge_essentials`): IAT, aceite de motor, aceite de caja y refrigerante en grande, rangos propios en °F y minutos para estar listo.

- **CASPER DRAGY'S** (`jorge_dragtimer`): 0-100, 100-200, 1/8 y 1/4 de milla con récords, usando los sensores del carro.

## Instalar

En el carro: Store → Ajustes → Agregar fuente → este repositorio, rama `main`. Instala la app y reinicia la unidad.
